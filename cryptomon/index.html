cryptomon

Your crypto portfolio, live, in a corner of your desktop.

Linux only. Prices come from CoinGecko's free public API and are indicative, not trading quotes. Not financial advice. Built and tested on Fedora with KDE Plasma.
  • Add any coin CoinGecko lists: search by name or symbol, enter how much you hold
  • Total value and 24h change, plus per coin price, value, 24h change and a 7 day sparkline
  • Opens on the left edge of the screen, with a system tray icon to hide or show it; GBP, USD or EUR, a refresh interval, adjustable opacity, optional click-through; remembers your coins and position
  • Private: only coin ids are sent to CoinGecko. How much you hold stays in a local config file
Download (.zip) Download (.tar.gz) GitHub

Install (adds an app-menu entry)

git clone https://github.com/kranmal/cryptomon && cd cryptomon && ./install.sh

Run

cryptomon

Try it with fake data first

cryptomon --demo
Requires Python 3.9+ and PySide6 (installed automatically). Right-click to add a coin; double-click a coin to edit its amount. Price data by CoinGecko. MIT licensed. See also: sysmon-widget, Linux Powermon.
