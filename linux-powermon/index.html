Linux Powermon

See what your PC costs to run, live, in a corner of your desktop.

Linux only. Reads Linux /sys sensors (CPU RAPL or zenergy, AMD GPU). Wall power is an estimate, usually within 10 to 15% of a plug-in meter. Built and tested on Fedora with KDE Plasma.
  • Live watts and cost per hour from your own unit rate, with a 60 second graph
  • kWh and cost for today, this session and this month, plus a day, month and year projection
  • One-click Energy Saver cuts CPU and GPU power and shows the watts saved
  • Tray icon: hover for live cost, click to hide or show, right-click for the menu
Download (.zip) Download (.tar.gz) GitHub

Install (adds an app-menu entry, optional autostart)

git clone https://github.com/kranmal/linux-powermon && cd linux-powermon && pip install --user -r requirements.txt && ./install.sh --autostart

Run

powermon

Try it with fake data first

python3 powermon.py --demo
Requires Python 3.10+, PySide6 and psutil. The energy saver asks for your password through polkit. MIT licensed. See also: sysmon-widget, Linux Speedtest.
