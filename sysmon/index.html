sysmon-widget

Transparent, draggable system monitor for your Linux desktop.

Linux only for now. Built and tested on Linux (Fedora, X11/XWayland). Windows and macOS aren't supported yet.
  • CPU with per-core bars and history, RAM and swap
  • GPU load, VRAM, temperature, power and fan (AMD amdgpu)
  • NVMe and motherboard temperatures, disk usage, locked LUKS volumes
  • WiFi, Ethernet and a live network graph
Download (.zip) Download (.tar.gz) GitHub

Install with pipx

pipx install git+https://github.com/kranmal/sysmon-widget

Or from source (adds an app-menu entry)

git clone https://github.com/kranmal/sysmon-widget && cd sysmon-widget && ./install.sh

Run

sysmon
Requires Python 3.9+ and a desktop session. PySide6 installs automatically. MIT licensed. See also: pollar-ticker.
