VacuumTube for macOS

YouTube TV on your Mac, as a desktop app. Apple silicon build.

Unofficial and unsigned. This is a build of VacuumTube 2.0.2 by shy1132 (MIT), cross-built on Linux, so macOS Gatekeeper blocks it until you clear the quarantine flag. Apple silicon (arm64) only. I have not been able to run it on a Mac myself.
Download (.zip, 112 MB) Download (.dmg, 420 MB, experimental) VacuumTube on GitHub

Install (use the .zip)

  1. Double-click VacuumTube-arm64.zip in Downloads. It unzips to VacuumTube.app.
  2. Drag VacuumTube.app to Applications.
  3. In Terminal, clear the quarantine flag (the app is not notarized, so macOS blocks it otherwise):
xattr -cr /Applications/VacuumTube.app
  1. Open VacuumTube from Applications.

Troubleshooting

  • "xattr: No such file": xattr is built into macOS; the error means the app is not at that path. Find it:
ls -d /Applications/VacuumTube.app ~/Downloads/VacuumTube.app ~/Downloads/*/VacuumTube.app
  • Then run xattr -cr on the path that exists. In Terminal, type xattr -cr with a trailing space and drag the app from Finder into the window to fill in the path.
  • Still blocked: right-click the app, choose Open, then confirm. Or allow it in System Settings, Privacy & Security.
  • The .dmg flashes and nothing happens: the .dmg is a raw HFS+ image built on Linux and untested on a Mac, and it may fail to mount. Use the .zip. To see why it failed:
hdiutil attach -verbose ~/Downloads/VacuumTube-arm64.dmg
  • If it does attach, you can convert it to a normal compressed dmg:
hdiutil convert ~/Downloads/VacuumTube-arm64.dmg -format UDZO -o ~/Downloads/VacuumTube-fixed.dmg
  • A dmg only mounts a disk and installs nothing: drag the app from it to Applications, then run the xattr step above on the copy in Applications (the mounted dmg is read-only).

Build the dmg yourself on a Mac

git clone https://github.com/shy1132/VacuumTube && cd VacuumTube && npm ci && npx electron-builder --mac dmg --arm64
